# styleforge

Google Flow（Veo）网页端自动化工作台：精准插入指定首帧图、截取上一段视频的尾帧、链式生成连续视频，尽量后台无人值守运行。

## Agent skills

### Issue tracker

Issues are tracked in this repo's GitHub Issues via the `gh` CLI (remote is created at first publish). See `docs/agents/issue-tracker.md`.

### Triage labels

Default five canonical triage labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one root `CONTEXT.md` + `docs/adr/`. See `docs/agents/domain.md`.
